# ตลาดอาหารหมู่บ้าน

ต้นแบบ PWA ภาษาไทย ใช้ข้อมูลในเบราว์เซอร์และรันด้วย Node.js ที่ติดตั้งไว้แล้ว

## ทดลองสั่งและขายในสองแท็บ

1. รัน `node serve.mjs` แล้วเปิด http://localhost:4173 หรือเปิดเว็บที่เผยแพร่บน GitHub Pages
2. เปิดสองแท็บในเบราว์เซอร์เดียวกัน แท็บแรกเลือก **แม่ค้า** กรอกชื่อแม่ค้าหรือชื่อร้าน ขายอะไร เบอร์สมมติ และโซน แนบภาพ QR ทดลองได้ แล้วใส่ OTP ที่แสดงบนหน้า
3. เพิ่มชื่อ รายละเอียด และราคาอาหาร แล้วกด **ลงขายเมนู** สามารถพักขายและเปิดขายอีกครั้งได้
4. อีกแท็บเลือก **ลูกค้า** ลงทะเบียนชื่อ บ้านเลขที่ เฟส และซอยด้วยข้อมูลสมมติ เลือกโซนเดียวกับร้านและจำนวน แล้วกด **ตรวจสอบออเดอร์** ตรวจที่อยู่จากโปรไฟล์ เลือกเงินสดหรือโอน / สแกน QR และเลือกรอรับหรือแขวนไว้หน้าบ้านก่อนยืนยัน
5. แท็บแม่ค้ากด **รับออเดอร์** แล้วเปลี่ยนเป็น **กำลังจัดส่ง** และ **ส่งแล้ว** หรือกดปฏิเสธขณะรอร้านรับ ผู้ซื้อยกเลิกได้ในช่วงเดียวกัน ทั้งสองฝ่ายดูประวัติและแชทในออเดอร์ได้
6. ลูกค้าให้คะแนน 1–5 ได้ครั้งเดียวหลังส่งแล้ว คะแนนเฉลี่ยของร้านคำนวณจากรีวิวเดิมและใหม่

ลูกค้าสามารถเลือก **สั่งแทน (ไม่ต้องลงทะเบียน)** แล้วกรอกบ้านเลขที่ เฟส และซอยของผู้รับในแต่ละออเดอร์ ที่อยู่นี้บันทึกในออเดอร์โดยไม่เปลี่ยนโปรไฟล์ลูกค้า

ลูกค้าปกติและแม่ค้าใช้โปรไฟล์ที่บันทึกไว้ในเบราว์เซอร์หลังลงทะเบียนครั้งแรก ลูกค้าแก้ที่อยู่ได้ และแม่ค้าเพิ่มหรือเปลี่ยน QR ของร้านได้ในหน้าแม่ค้า เมื่อเลือกโอน ระบบแสดงภาพ QR ของร้านในหน้าตรวจสอบออเดอร์ ร้านที่ยังไม่มี QR รับเงินสดได้ ระบบไม่มีการตรวจสอบยอดโอน หากสั่งเมนูร้านตัวอย่าง ให้เลือกชื่อร้านตัวอย่างจากช่อง **ร้านที่จัดการ** ในหน้าแม่ค้าเพื่อจำลองการรับออเดอร์ ข้อมูลแยกตามเบราว์เซอร์และ URL เดิม คะแนนรีวิวเดิมยังนำมาคำนวณ ส่วนออเดอร์เดิมที่ผูกกับเบอร์ยังดูได้ผ่านภาพรวมแอดมินทดลอง

เมื่อ Service Worker พร้อมหลังโหลดออนไลน์แล้ว สามารถเปิดต้นแบบและใช้ข้อมูลในเบราว์เซอร์ขณะออฟไลน์ได้

## โครง MVP อาหารสำหรับใช้จริงในอนาคต

| ส่วน | ออกแบบไว้ |
| --- | --- |
| สมาชิกและสิทธิ์ | ยืนยันเบอร์ด้วย OTP จริง ให้ผู้ใช้สลับโหมดซื้อและขายเมื่อได้รับสิทธิ์ร้านค้า เซิร์ฟเวอร์ตรวจสิทธิ์ของทุกคำขอ แยกสิทธิ์แอดมินและบันทึกการแก้ไข |
| โซนและร้าน | แอดมินดูแลโซนและอนุมัติร้าน ผู้ขายตั้งเมนู ราคา เวลาเปิด และพื้นที่จัดส่ง ลูกค้าเห็นร้านที่จัดส่งถึงบ้าน |
| ออเดอร์ | หนึ่งร้านต่อออเดอร์ รวมราคาและค่าจัดส่งฝั่งเซิร์ฟเวอร์ ใช้ธุรกรรมป้องกันการสร้างซ้ำ เก็บประวัติสถานะ รองรับปฏิเสธและยกเลิก ร้านจัดส่งเอง |
| แชทและรีวิว | ห้องแชทตามออเดอร์สำหรับคู่รายการ รีวิว 1–5 เฉพาะผู้ซื้อที่ได้รับอาหาร หนึ่งคะแนนต่อออเดอร์ |
| Realtime และ Push | ฟังเฉพาะออเดอร์ที่มีสิทธิ์และจำกัดช่วงข้อมูล ส่ง Push ผ่านระบบฝั่งเซิร์ฟเวอร์เมื่อสร้างออเดอร์หรือเปลี่ยนสถานะ พร้อมป้องกันการแจ้งเตือนซ้ำ |
| PWA | ทดสอบบน Android และ iPhone จริงผ่าน HTTPS รวมการติดตั้ง การขอสิทธิ์ Push และการแตะแจ้งเตือนเพื่อเปิดออเดอร์ |

## งบรอบจำลอง

ใช้จริง 0 บาทจากงบตั้งต้น 2,000 บาท ไม่รวมประชาสัมพันธ์ ยังไม่ได้สร้างบัญชี ผูกบัตร ซื้อโดเมน หรือเผยแพร่เว็บ เก็บการเทียบราคา OTP จริง โฮสต์ รูปเมนู และระบบส่ง Push ไว้ตอนพิจารณาเปิดทดลอง ระบบจริงต้องประเมินจากจำนวน OTP และการอ่านข้อมูลที่วัดได้ในกลุ่มนำร่องก่อนขยายสู่ 2,000–3,000 หลังคาเรือน
