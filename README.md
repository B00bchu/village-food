# ตลาดอาหารหมู่บ้าน

ต้นแบบ PWA ภาษาไทย ใช้ข้อมูลในเบราว์เซอร์และรันด้วย Node.js ที่ติดตั้งไว้แล้ว

## ลองตั้งแต่สั่งจนให้คะแนน

1. รัน `node serve.mjs` ในโฟลเดอร์นี้ แล้วเปิด http://localhost:4173
2. ใช้เบอร์สมมติ เช่น 0800000000 ขอ OTP และกรอกรหัส 6 หลักที่ปรากฏในหน้า
3. เลือกโซนและสั่งอาหาร ร้านค้าทดลองมีหนึ่งร้านต่อโซน
4. เปิดโหมดร้านค้า เลือกร้านของออเดอร์ แล้วกดเปลี่ยนสถานะทีละขั้นจนส่งแล้ว
5. กลับหน้า “ซื้ออาหาร” ให้คะแนน 1–5 ได้หนึ่งครั้งต่อออเดอร์ที่ส่งแล้ว คะแนนเฉลี่ยแสดงในรายการอาหารของร้าน
6. เปิดโหมดแอดมินเพื่อดูออเดอร์ทั้งหมดและจำนวนที่กำลังดำเนินการ

ข้อมูลอยู่ในเบราว์เซอร์เครื่องนี้ เปิดสองแท็บในเบราว์เซอร์เดียวกันเพื่อดูการอัปเดตจำลองระหว่างแท็บ โหมดผู้ขายและแอดมินเปิดให้สลับเพื่อสาธิต การเข้าสู่ระบบทดลองสิ้นสุดเมื่อรีเฟรช

## ฟีเจอร์ที่เพิ่มในต้นแบบ

- ผู้ซื้อยกเลิกและร้านค้าปฏิเสธได้ในสถานะ “รอร้านรับ” หลังจากนั้นร้านเดินสถานะจนส่งแล้วได้ตามเดิม
- เปิด “ประวัติสถานะ” ในการ์ดออเดอร์เพื่อดูเวลาเปลี่ยนสถานะ ออเดอร์เดิมเริ่มแสดงประวัติจากสถานะที่เก็บไว้เดิม
- เปิด “แชทออเดอร์” จากหน้าผู้ซื้อหรือร้านค้า แล้วส่งข้อความได้ทันทีในเบราว์เซอร์เดียวกัน ลองเปิดสองแท็บเพื่อสลับบทบาท
- ออเดอร์และคะแนนรีวิวเดิมยังอ่านจากที่เก็บเดิมในเบราว์เซอร์เมื่อใช้ URL เดิม ไม่มีการสร้างคะแนนเพิ่มอัตโนมัติ
- เมื่อเปิดเว็บออนไลน์ครั้งแรกจน Service Worker พร้อมใช้งาน สามารถเปิดหน้าต้นแบบและใช้ข้อมูลในเบราว์เซอร์เมื่อออฟไลน์ได้

## โครง MVP อาหารสำหรับใช้จริงในอนาคต

| ส่วน | ออกแบบไว้ |
| --- | --- |
| สมาชิกและสิทธิ์ | ยืนยันเบอร์ด้วย OTP จริง ให้ผู้ใช้สลับโหมดซื้อและขายเมื่อได้รับสิทธิ์ร้านค้า เซิร์ฟเวอร์ตรวจสิทธิ์ของทุกคำขอ แยกสิทธิ์แอดมินและบันทึกการแก้ไข |
| โซนและร้าน | แอดมินดูแลโซนและอนุมัติร้าน ผู้ขายตั้งเมนู ราคา เวลาเปิด และพื้นที่จัดส่ง ลูกค้าเห็นร้านที่จัดส่งถึงบ้าน |
| ออเดอร์ | หนึ่งร้านต่อออเดอร์ รวมราคาและค่าจัดส่งฝั่งเซิร์ฟเวอร์ ใช้ธุรกรรมป้องกันการสร้างซ้ำ เก็บประวัติสถานะ รองรับปฏิเสธและยกเลิก ร้านจัดส่งเอง |
| แชทและรีวิว | ห้องแชทตามออเดอร์สำหรับคู่รายการ รีวิว 1–5 เฉพาะผู้ซื้อที่ได้รับอาหาร หนึ่งคะแนนต่อออเดอร์ |
| Realtime และ Push | ฟังเฉพาะออเดอร์ที่มีสิทธิ์และจำกัดช่วงข้อมูล ส่ง Push ผ่านระบบฝั่งเซิร์ฟเวอร์เมื่อสร้างออเดอร์หรือเปลี่ยนสถานะ พร้อมป้องกันการแจ้งเตือนซ้ำ |
| PWA | ทดสอบบน Android และ iPhone จริงผ่าน HTTPS รวมการติดตั้ง การขอสิทธิ์ Push และการแตะแจ้งเตือนเพื่อเปิดออเดอร์ |

## งบรอบจำลอง

ใช้จริง 0 บาทจากงบตั้งต้น 2,000 บาท ไม่รวมประชาสัมพันธ์ ยังไม่ได้สร้างบัญชี ผูกบัตร ซื้อโดเมน หรือเผยแพร่เว็บ เก็บการเทียบราคา OTP จริง โฮสต์ รูปเมนู และระบบส่ง Push ไว้ตอนพิจารณาเปิดทดลอง ระบบจริงต้องประเมินจากจำนวน OTP และการอ่านข้อมูลที่วัดได้ในกลุ่มนำร่องก่อนขยายสู่ 2,000–3,000 หลังคาเรือน
