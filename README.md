# ตลาดอาหารหมู่บ้าน

ต้นแบบ PWA ภาษาไทย ใช้ข้อมูลในเบราว์เซอร์และรันด้วย Node.js ที่ติดตั้งไว้แล้ว

## สถานะการเปิดใช้งาน

หน้า GitHub Pages แสดงหน้าประกาศพักรับคำสั่งซื้อและลงทะเบียนร้านค้า จนกว่าจะมีระบบบัญชีและฐานข้อมูลร่วมที่ใช้ข้ามเครื่องได้ หน้าร้านและออเดอร์ในเบราว์เซอร์จากรุ่นก่อนยังเป็นข้อมูลเฉพาะเครื่อง

ใช้ `node serve.mjs` และเปิด http://localhost:4173 เพื่อพัฒนาตะกร้าและทดสอบข้อมูลในเครื่อง โหมดแม่ค้าใช้ร้านที่มีอยู่แล้วในเบราว์เซอร์ การลงทะเบียนร้านใหม่รอระบบบัญชีจริง

ตะกร้ารองรับหลายร้านในครั้งเดียว แสดงยอดแต่ละร้านและยอดรวม ให้เลือกเงินสดหรือโอนแยกต่อร้าน หากร้านมี QR และเลือกโอน ระบบแสดง QR ของร้านพร้อมยอดที่ต้องกรอก ออเดอร์จะแยกตามร้านหลังยืนยัน และไม่มีการตรวจสอบยอดโอนอัตโนมัติ

## โครง MVP อาหารสำหรับใช้จริงในอนาคต

| ส่วน | ออกแบบไว้ |
| --- | --- |
| สมาชิกและสิทธิ์ | ใช้บัญชีร้านที่ยืนยันตัวตนด้วยรหัสผ่านหรือผู้ให้บริการเข้าสู่ระบบ ให้ผู้ใช้สลับโหมดซื้อและขายเมื่อได้รับสิทธิ์ร้านค้า เซิร์ฟเวอร์ตรวจสิทธิ์ของทุกคำขอ แยกสิทธิ์แอดมินและบันทึกการแก้ไข |
| ร้านค้า | แอดมินอนุมัติร้าน ผู้ขายตั้งเมนู ราคา และเวลาเปิด ลูกค้าค้นหาชื่อร้านหรือเมนูได้ |
| ออเดอร์ | หนึ่งร้านต่อออเดอร์ รวมราคาและค่าจัดส่งฝั่งเซิร์ฟเวอร์ ใช้ธุรกรรมป้องกันการสร้างซ้ำ เก็บประวัติสถานะ รองรับปฏิเสธและยกเลิก ร้านจัดส่งเอง |
| แชทและรีวิว | ห้องแชทตามออเดอร์สำหรับคู่รายการ รีวิว 1–5 เฉพาะผู้ซื้อที่ได้รับอาหาร หนึ่งคะแนนต่อออเดอร์ |
| Realtime และ Push | ฟังเฉพาะออเดอร์ที่มีสิทธิ์และจำกัดช่วงข้อมูล ส่ง Push ผ่านระบบฝั่งเซิร์ฟเวอร์เมื่อสร้างออเดอร์หรือเปลี่ยนสถานะ พร้อมป้องกันการแจ้งเตือนซ้ำ |
| PWA | ทดสอบบน Android และ iPhone จริงผ่าน HTTPS รวมการติดตั้ง การขอสิทธิ์ Push และการแตะแจ้งเตือนเพื่อเปิดออเดอร์ |

## ค่าใช้จ่าย

GitHub Pages ใช้สำหรับเผยแพร่หน้าเว็บ ส่วนการเปิดรับออเดอร์จริงต้องมีโฮสต์ฐานข้อมูล ระบบบัญชีร้านค้า และพื้นที่เก็บภาพที่เว็บไซต์เข้าถึงได้
